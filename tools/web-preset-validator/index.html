What gets validated & how to fix the common issues

Top-level shape. A preset is one JSON object with displayname (string), schemaversion (int — current is 9), valid (0 or 1; 0 means the in-game MCM will treat it as deleted), optional transition.duration (seconds, float), optional fadeondeath block, and exactly 8 slot entries.

Per slot. Every slot is shaped:

  • cond: { pluginid, packid, entryid, param, param2 } — empty strings & 0 for the Default (slot 0) row. param / param2 may be int (slider) or string (menu id) depending on what the bound plugin declares.
  • name (optional, v0.2.9): per-slot display-name override. Empty string → use the plugin's canonical condition label.
  • persist.min / persist.allowOverride / cool.min — schema-8 cooldown rework. Old cooldown.min / cooldown.mode still validate but get ignored on load.
  • pulse (optional): rate (Hz), depth (0–100), pause (s), waveform (name from waveforms/).
  • layer (optional, up to 4): tint + emissive as "#RRGGBB" strings (or decimal int 0–16777215), emissivemult float, alpha 0–100.
  • effect (optional, up to 32): key in pluginid:effectid form (e.g. mtf.base:damage.magicka); param1…param5 may be int (slider) or string (menu id) per the bound effect's declaration.

Errors vs. warnings. Errors block the download button — they're things the in-game loader will reject or that will produce silently wrong behavior. Warnings are advisory: legacy keys still present after a schema bump, unknown fields that look like typos, or valid: 0 which would make the preset show up as deleted in-game.

Output filename. The file inside the ZIP is derived from displayname: kept chars are A-Z a-z 0-9 _ -, everything else becomes _, capped at 32 characters. That's exactly the same sanitization the in-game SavePreset uses, so your file lands where the MCM expects it.

Privacy. Validation and ZIP packing run entirely in your browser. The preset never leaves your machine.

Schema reference lives in MTF_MainQuest.psc (search for SavePreset / LoadPreset). ZIP packaging via JSZip. Source: tools/web-preset-validator/.
