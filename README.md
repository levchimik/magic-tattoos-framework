# LewdMarks Effects

Skyrim SE/AE plugin adding condition-based dynamic overlay rendering on top of LewdMarks tattoos.

Up to 7 condition slots + 1 default slot, each with its own texture/tint/emission/glow configuration.
Built-in conditions: Arousal (SLA), Pregnancy (FMR), Ovulation (FMR), Magicka %, active Magic Effects.

## Requirements
- LewdMarks (textures)
- RaceMenu / SKEE (NiOverride)
- SexLab Aroused (for Arousal condition)
- Fertility Mode Reloaded (for Pregnancy/Ovulation conditions)
